# AIoT 协会开源项目孵化中心

这里是华侨大学 AIoT 协会用于收录、孵化和展示暂未归属到特定竞赛或专题的开源项目的入口仓库。

> 本仓库只保存项目索引、申请流程和治理文档，不集中存放各项目源码。通过审核的项目使用独立仓库，确保提交历史、许可证和协作权限彼此隔离。

## 适合收录的项目

- 协会成员自主发起的硬件、通信与物联网、AI 视觉及算法、机械等开源项目。
- 暂未归属到特定竞赛、课程或专题，但具备明确目标和持续维护意愿的项目。
- 已在个人账号下开发、计划转移至 `HQU-AIot` 组织的项目。

以下内容不予收录：来源或再发布授权不明确的代码、包含密钥或个人敏感信息的内容，以及仅用于临时文件共享的仓库。

## 申请流程

1. 打开“项目孵化申请”Issue 表单。
2. 填写项目名称、负责人、简介、技术方向、许可证和仓库来源。
3. 维护者核对名称、授权情况和基本资料。
4. 审核通过后，新建独立组织仓库或接收现有仓库转移。
5. 将项目加入下方索引，并由负责人维护自己的项目仓库。

## 基本要求

- 每个项目必须有明确的 GitHub 负责人。
- 每个项目必须独立选择开源许可证；本仓库的 MIT License 不会自动适用于其他项目。
- 新仓库至少应包含 `README.md`、许可证文件和基本使用说明。
- 不得提交令牌、密码、私钥、个人信息或其他不应公开的数据。
- 项目负责人管理自己的仓库；其他普通成员默认不应拥有直接写入权限。

## 参与讨论

- 新项目请通过 Issue 表单提交申请。
- 一般建议、跨项目交流和孵化经验可在 Discussions 中讨论。
- 具体项目的问题应提交到对应的独立项目仓库。
